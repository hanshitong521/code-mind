# analysis · D1 分析与取证

**先分析，再画图。** 跳过分析直接画 = 编图。

## D0 出口（先于节点表）

```
读者三问：〔30 秒要回答什么〕
输入类型：〔架构 / 流程 / 事故排查 / 数据模型 / 混合〕
选用标注：〔从 annotation.md 菜单勾选 0~N 项，可全空〕
```

## 输入类型 → 策略

| 输入 | 怎么抽 | 常见选用标注 |
|------|--------|-------------|
| 需求文档 / PRD | **角色**、**动作**、**数据**、**规则** | 通常无；缺信息 → UNKNOWN |
| 代码仓 | **入口** → **服务** → **存储** → **外部** | 通常无 |
| README / 架构 MD | **模块**与**依赖**；声称 vs 实际 | 通常无 |
| 事故 / 日志 / 监控 | 现象 → 假设 → 验证 → 根因 | 关键数字、时间锚点、排查态（**有证据才勾**） |
| 混合 | 文档定骨架，代码纠偏 | 按主问题勾选 |

## 提节点（6 类）

| 类 | 信号 | 证据要求 |
|----|------|---------|
| 角色 | 用户/管理员/外部系统/定时任务 | 需求原话 |
| 入口 | Controller / route / main / CLI | `path:line` |
| 模块/服务 | Service / usecase / module / 包 | `path:line` |
| 存储 | DB / Repository / DAO / cache | `path:line` |
| 外部 | HTTP client / SDK / MQ / 第三方 | `path:line` |
| 队列/事件 | topic / event / listener | `path:line` |

## 提边（4 类，必须标语义）

| 类 | 信号 | 标注 |
|----|------|------|
| 调用 | 方法调用 / RPC / HTTP | `-->|调用|` |
| 数据流 | 读写 / 落库 / 缓存 | `-->|写|` `-->|读|` |
| 依赖 | import / 注入 / 组合 | `-->|依赖|` |
| 事件 | 发布/订阅 | `-->|发布|` |

## 中间产物（D1 出口）

画图前先产出两张表，**不许直接跳到 DSL**：

```
## 节点表
| ID | 显示名（人话，进图） | 类型 | 加注 | 证据（不进图） |
|----|---------------------|------|------|----------------|
| gw | 网关 | 入口 | — | src/gateway/... |
| job | 定时补券 | 入口 | 时间+数（若有） | path:line；日志 |

## 边表
| 从 | 到 | 语义（人话，进图） | 证据（不进图） |
|----|----|-------------------|----------------|
| job | svc | 触发补券 | Feign 调用 path:line |
```

**加注列**：仅填 D0 勾选项（数字/态/时间/—）。**证据列**进 §0，不进图。

## 证据规则（硬）

| 情况 | 处理 |
|------|------|
| 有 `path:line` | 直接进节点表 |
| 只有需求原话 | 进节点表，证据写原话 |
| 只有推测 | **不进节点表** → 进未知清单 |
| 文档声称但代码查不到 | 标注 `⚠️ 文档声称，代码未验证` |

**禁止**：凭模型常识补全"应该有的模块"（如"一般都会有鉴权"）。项目里没有就是没有。
