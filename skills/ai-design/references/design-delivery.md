# design-delivery · D7 设计交付

`docs/diagram/design.md` **一份文件双职**：

- 给人：30 秒看懂 —— 1 张架构图 + 表格；
- 给 `/ai-code`：结构化契约 —— 文件尾的 `design_to_code` Handoff YAML（schema = `shared/handoff-schema.yaml`）。

**没有第二份文档。** 图和契约同源同文件，才不会出现「图改了 YAML 没改」。

## 何时产出

| 场景 | D7 |
|------|-----|
| 纯理解（只画系统图，不动代码） | 跳过，并在图下注明「纯理解，无变更」 |
| 本次要改代码 | **必产 / 必更新** |

判据：本次有代码变更 → 必产；否则跳过。

## 文件格式 `docs/diagram/design.md`

````markdown
# <系统名> 技术设计

> 一句话：这是什么、给谁用。

![架构图](assets/design.svg)

```mermaid
<唯一一张图>
```

## 1. 分层职责
| 层 | 谁 | 只做 | 不碰 |

## 2. 工件链（下游 AI 直接消费）
| # | 生产者 | 工件 | 落盘位置 | 消费者 |

## 3. 命令 / 接口
| 命令 | 作用 | 何时用 |

## 4. 风险
| # | 风险 | 级别 | 影响 | 处置 |

## 5. 未知 / 待确认
| # | 问题 | 状态 | 需要 |

## 6. 本次变更面
一句话：改哪一层、哪个模块。

## 7. 验收
| # | 判据（可 TDD 化） | 证据 |
|---|------------------|------|
| 1 | `func('in') == 'out'` | 待跑 |

```yaml
变更面: backend/api
plan路径: "@docs/diagram/design.md"
范围: 模块X 表Y 接口Z
验收: 验收表 #1-#3
验证档位: surface
建议下一步: /ai-code
```
````

**约束**：`mermaid` 块必须是文档里**第一个也是唯一一个**图块 —— `render.mjs` 默认只渲第一个，多写的会被忽略并告警。

## 字段从哪来（禁凭空写）

| 字段 | 来源 |
|------|------|
| 变更面 | 图里受影响的层/模块 |
| plan路径 | `@docs/diagram/design.md`（本文件，固定） |
| 范围 | 图上的节点集合 |
| 验收 | 每条关键**边**是否成立 → 转成可测判据 |
| 验证档位 | `shared/verification-policy.yaml`（默认 `surface`，涉身份矩阵升级） |
| 建议下一步 | `/ai-code` 或 `无` |

## 硬规则

- YAML 块必须能过 `python scripts/validate_handoff.py docs/diagram/design.md`（FAIL → 禁交 `/ai-code`）。
- **禁止文件路径/行号**进 YAML（会过期）；行为契约写模块/表/接口/状态机。
- 未知项进「未知 / 待确认」，**不许猜**（与 `unknowns-risks.md` 同纪律）。
- 验收判据必须可 TDD 化：`func('input')=='output'`，禁「看起来对」。
- 改了图就要重跑 `render.mjs`，否则 `assets/design.svg` 与图源脱节。

## 与图的分工

| 载体 | 给谁 | 负责 |
|------|------|------|
| 文档里的**图** | 产品/运维/老板 + Agent | 拓扑、依赖、层次 —— 「看懂」（**人话，禁类名**） |
| **§0 节点证据表** | 开发 + Agent | `path:line`、日志 —— 「有据可查」 |
| **§关键数字 / §排查脉络** | 人 + Agent | **可选**；仅 D0 勾选且有据时保留 |
| 文档里的**其它表格** | 下游 Agent | 清单、映射、判据 —— 「照着做」 |
| 文档尾的 **YAML** | `/ai-code` | 机器消费的交接契约 —— 「动手」 |

**图负责「看懂」，§0 负责「有据」，YAML 负责「动手」。** YAML 的范围必须能在图上找到对应**人话节点**。

## 出口检查

- [ ] 本次有代码变更 → `design.md` 已产出/已更新？
- [ ] 图块只有一个，且已重跑渲染？
- [ ] YAML 块字段齐全（变更面/plan路径/范围/验收/验证档位/建议下一步）？
- [ ] 验收判据可机器检查？
- [ ] 未知项没被写成确定结论？
