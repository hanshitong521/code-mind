# Levels & Explain Dial — 强度阶梯 · 受众档 · 竞品差异

## 1. 强度阶梯

| Level | 名称 | 行为 | 何时用 |
|-------|------|------|--------|
| L0 | off | 不压缩（= latch OFF） | `stop concise-mind` |
| **L1** | terse | 删套话/表扬/旁白；允许短句与省略主语；术语原样 | **默认** |
| L2 | strict | 追加：段落 ≤ 3 句；表格仅在 ≥2 列事实时使用；列表 ≤ 5 项且按相关性排序；禁止嵌套 > 2 层 | `l3` 之外要更紧、或长会话 |
| L3 | redline | 电报体；可省虚词与连接词；保留 `decision/evidence` 骨架 | `/concise-mind l3`、token 告急 |

**不变量（所有 Level 共有）**：事实、数字、路径、错误原文、代码、`decision/evidence/risk/verification` 一律不得因压缩而失真。安全性/不可逆操作 → 临时退回完整句（安全优先于省 token）。

## 2. Explain 档（受众）

触发：`eli5` `说人话` `通俗` `把 X 讲给 <受众> 听` / `eli5:<audience>`

| 受众 | 词汇 | 类比来源 | 深度 |
|------|------|----------|------|
| `5岁` / `10岁` | 零术语 | 玩具、积木、找东西 | 一张图 + 3 句 |
| `15岁` | 少量术语 | 游戏、社交、手机 | 4 句 + 1 图 |
| `非技术` / `manager` | 无术语，给结论与影响 | 成本、风险、决策 | 3 句：是什么/影响/要你做什么 |
| `engineer` | 术语照用 | 系统、数据流 | 保留 tradeoff 与边界 |
| `designer` | 少术语，给行为差异 | 交互、状态 | 给"用户会看到什么变化" |

篇幅：Explain 在 CHAT/CODE 下 ≤ 5 句；ARCH/HANDOFF/INCIDENT 仍受各模式五元组约束。

### 精度护栏（相对 eli5 的关键差异）

**简化不得改变事实。** 明确禁止的「通俗化」：

| 禁 | 因为 |
|----|------|
| 「哈希可以解密」 | 单向 ≠ 可逆，属错误断言 |
| 「加索引一定更快」 | 写放大、选择性差时相反 |
| 「缓存就是更快的数据库」 | 一致性代价被抹掉 |
| 「删掉日志没影响」 | 不可观测性风险 |
| 任何为顺口而删掉的**前提条件** | 前提即事实 |

规则：**比喻允许模糊"怎么做到"，不允许错"能不能""会不会"。** 拿不准 → 说"这里简化了，细节差别在 X"。

## 3. 需要图时（对 eli5 的正面回应）

用户要「看懂 / 讲清楚 / 画一下」→ 在 3–5 句之外**补一张图**（`show_widget` / Mermaid），而不是靠文字变长。图是压 token 的手段，不是装饰。

## 4. 竞品差异（客观）

| 维度 | eli5 (Anthropic 社区) | caveman-ultra | ponytail | **concise-mind v4** |
|------|----------------------|---------------|----------|---------------------|
| 形态 | 单次生成 HTML 大图 | 常驻语气规则 | 反过度设计 | 常驻引导 + 锁存 skill |
| 会话持续 | ✗ 一次一条 | ✓（alwaysApply） | ✓ | **✓ 锁存，含文档/Plan** |
| 模式感知 | ✗ 只有"简化"一种 | ✗ 只有"短" | ✗ 只砍复杂度 | **✓ 七模式 + 预算** |
| 写文档 | ✗ 输出 HTML 工件，非文档流水线 | 部分 | ✗ | **✓ DOC 模式 + 去水率门** |
| Plan 模式 | ✗ | ✓ | ✓ | **✓ PLAN 模式（目标/步骤/验证/风险/回滚）** |
| 精度护栏 | 明示会牺牲严谨 | 无 | 无 | **✓ 五元组 Gate + 禁错清单** |
| 可验证 | 无评测 | 无 | 无 | **✓ evals.json + 零依赖评分器** |
| 可视化 | ✓ 强项（大图少字） | ✗ | ✗ | 部分（按需出图，不为图而图） |

**打法**：eli5 赢在"图"；v4 赢在**持续 + 结构性保留 + 不出错 + 可打分**。二者不冲突——要图时用 eli5 式出图，要**文档/计划/长会话**时用 v4。
