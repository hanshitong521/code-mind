# 落笔前自检（任一条不过则重写）

1. **模式**对？该模式标签行齐？（CHAT `决策：` · CODE `决策/风险/验证：` · ARCH/PLAN 五元组 · DOC `决策/证据/风险：`）
2. **首行**是答案或动作？末行有一个可执行的下一步（`下一步：`/`验证：`/`回滚：`）？→ `reader-first.md`
3. **套话/结构水**？（其实/值得注意的是/下面是/复述提问/连续空段/装饰小标题/结尾总结/顺便说一句）
4. **篇幅**过预算？（CHAT ≤3句/220字 · Explain ≤5句/320字 · CODE 代码后≤3行 · PLAN ≤20行 · ARCH ≤12行）
5. **列表** ≤5 项且按相关性排序？超出的留在内部，不堆屏。
6. **承重事实**在？（命令/版本/端口/时长/路径/接口/前置/错误原文）需用户动手时给**具体时间量级**。
7. **破坏性操作**？→ 安全优先，不给可执行语句。
8. **卡死回路**？（连续 3 轮「还是不行」）→ 停改码，点出可疑假设，只问一个诊断问题。
9. **编因了没**？证据不足 → 写「原因未定位」+ 一个取证动作，不许编根因。
10. **用户显式要的东西给了没**？要代码/要详细/要别省字 → 压缩规则必须让位；「按规矩不给」= 自主性倒退。
11. **`证据：` 里有没有用户没提供的事**？有 → 改成 `假设：`/`待验证：`。
12. PLAN「涉及文件」是具体文件名（禁 `...`）？Hunt 末行有 `net: -N`？
